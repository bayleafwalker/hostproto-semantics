## Facts learned that are not in any spec changelog

1. On the 2026-07-28 era `resources/subscribe` **does not exist**; the client
   SDK refuses it. Subscribe by listing URIs in the listen filter; the
   server honours them only if it declares `resources.subscribe`.
2. `server/discover` returns `{supportedVersions, capabilities, instructions}`;
   identity rides `_meta` (`io.modelcontextprotocol/serverInfo`).
3. MCP defines no handle concept — its stateful-tools guidance is
   non-normative. HostProto's `handles` schema is needed, not duplicated.
4. `tasks/list` was removed from the Tasks extension; listing is A2A's.
5. In browser-workbench: "blocked" is also where an infrastructure defect
   hides if nobody reads the reason (ADR-S6-03).
